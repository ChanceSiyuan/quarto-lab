# Share one curated reading map between humans and agents

Each trusted topic index owns an explicit `## Reading map` whose ordered direct links are the sole navigation authority. The Quarto sidebar, generated topic table, and deterministic agent resolver all consume the same validated Knowledge Graph derived from these maps; neither filesystem enumeration nor a separate search index may silently reorder or add trusted pages. This keeps the path a human browses identical to the Reading Bundle an agent must read before answering.

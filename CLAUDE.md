# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

This is a personal academic website/digital garden built with **Quarto**, focused on quantum computing research. The site contains theory notes, experimental documentation, and work-in-progress projects.

## Common Commands

```bash
# Build the static website (outputs to _site/)
./scripts/render_site.sh

# Start local preview server on port 4200
quarto preview
```

If the local `.venv` is broken, render on the remote DGX instead — see the
`render-site` skill.

## Architecture

**Content Sections:**
- `theory/<Section>/` - One directory per research topic (notes, section `refs.bib`, generated `index.qmd`)
- `Experiments/` - Experimental notes (PDH locking, Rb87 MOT)
- `life/` - Personal notes

Navigation, sidebars, and section note tables are generated by
`scripts/update_theory_nav.py` (pre-render hook) — never hand-edit the
`AUTO`-marked blocks.

**Key Files:**
- `_quarto.yml` - Main Quarto configuration (navigation, theme, bibliography settings)
- `references.bib` - Shared bibliography
- `aps.csl` - APS citation style
- `styles.css` - Custom styling

**Output:**
- `_site/` - Generated static website (do not edit directly)

## Content Format

All content is written in Quarto Markdown (`.qmd` files). Key features used:
- KaTeX for math rendering
- Bibliography citations via `references.bib`
- Jupyter integration for Python code cells

## Skills

Agent workflows live as skills in `skills/` (sources, committed; registered
in `Ion.toml`). `./scripts/install_skills.sh` installs them — plus the
third-party skills pinned in `Ion.lock` — as real copies (no symlinks) into
BOTH consumer dirs: `.claude/skills/` (read by Claude Code) and
`.agents/skills/` (read natively by Codex CLI). Both dirs are gitignored
and regenerable. After editing a local skill, re-run the script. Local
skills:

- `render-site` - build/preview the site correctly (incl. remote-DGX rendering)
- `download-ref` - add papers to the literature KB (`.knowledge/literature/`)
- `screen-paper` - rapid relevance triage of a paper
- `expand-notes` - expand rough notes/tex into Quarto reading notes
- `complete-gaps` - fill `(t.b.c.)`/`(todo:*)` placeholders rigorously
- `integrate-paper` - move qmd results into a LaTeX manuscript
- `generate-issues` - propose research issues from a note
- `conference-survey` - triage conference orals for a topic

Legacy paste-into-Claude prompts remain archived in `_instructions/`.

Runtime requirements: `context7-cli` and `arxiv-search` shell out to
`node`/`npx` — present on the laptop side, absent on the DGX, so run those
two skills from the laptop. Everything else is plain python3/bash.

Third-party skills reference their own bundled files as `skills/<name>/…`
(their upstream layout); in this repo those files actually live at
`.claude/skills/<name>/…` (e.g. `paper-writer`'s `references.md`).

## Deployment

The old `sync.sh` deploy script was removed (commit f4a0491); the repo
currently has no deploy script. Rendering is covered by the `render-site`
skill; ask the user before attempting any deployment.

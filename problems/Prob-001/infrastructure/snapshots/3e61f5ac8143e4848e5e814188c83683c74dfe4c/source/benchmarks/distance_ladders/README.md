# Distance Ladders

This directory stores deterministic CSS benchmark ladders for code-distance
algorithm experiments. A ladder chooses the code instances; `qec-code` generates
the actual parity-check matrices.

## Surface, Toric, and BB v1

The first ladder is defined by:

```text
benchmarks/distance_ladders/surface-toric-bb-v1.json
```

It currently includes:

- rotated surface code: `d=5,9,13`
- toric code: `d=5,9,13`
- BB72: `[[72,12,6]]`
- BB144: `[[144,12,12]]`

Materialize or refresh the checked-in sparse-row matrices with:

```bash
cargo run --bin autoqec-distance-ladder -- export \
  --manifest benchmarks/distance_ladders/surface-toric-bb-v1.json \
  --qec-code-bin qec-code \
  --force
```

Each generated instance directory contains:

- `instance.json`: metadata, expected distance, and qec-code command
- `hx.json`: sparse-row X-check matrix
- `hz.json`: sparse-row Z-check matrix

The file `surface-toric-bb-v1/distance-results.csv` is the working table for
comparing distance methods. Fill one row per `(instance, method)` with the
computed distance, bound type, elapsed time, command, and notes.

## Snapshot Status

This ladder is currently a research checkpoint while `rstim/qec-code` grows the
distance algorithms needed to rerun it cleanly from the qec-code CLI.

Tracked upstream work:

- rstim [#225](https://github.com/nzy1997/rstim/issues/225): add an
  RW/RIS-style randomized upper-bound method for CSS distance.
- rstim [#227](https://github.com/nzy1997/rstim/issues/227): expose ILP backend
  and time-limit options in the exact CSS distance CLI.
- rstim [#236](https://github.com/nzy1997/rstim/issues/236): track future
  DEM/circuit-distance solvers inspired by Stim undetectable-error search.

Checked-in result files:

- `surface-toric-bb-v1/distance-results.csv`: current qec-code randomized
  upper bound and Gurobi ILP exact runs with a 300 second cap.
- `surface-toric-bb-v1/random-window-results.csv`: an independent temporary
  Rust RW/RIS diagnostic runner; saved as evidence only.
- `surface-toric-bb-v1/codedistance-external-results.csv`: external
  `codeDistancePYPI` oracle runs for `QDistRndMW`, `QDistEvol`, and
  `decoderDist`; saved as evidence only.
- `surface-toric-bb-v1/randomized-comparison.csv`: compact comparison of the
  naive qec-code randomized method, the temporary Rust RW/RIS runner, and ILP.
- `surface-toric-bb-v1/algorithm-comparison.csv`: full comparison table across
  all recorded solvers.

The external source checkouts, virtual environments, and temporary runners used
to produce the diagnostic rows are intentionally not vendored into this
repository. Once rstim implements the upstream issues above, this ladder should
be rerun from the qec-code CLI and the diagnostic rows can be replaced by native
rstim/qec-code results.

## Expanded Native rstim #225 v2

The expanded ladder is defined by:

```text
benchmarks/distance_ladders/surface-toric-bb-kasai-tanner-v2.json
```

It keeps the original surface/toric/BB rows and adds:

- rotated surface code: `d=17,21`
- toric code: `d=17,21`
- larger same-shift BB stress cases: `[[288,16,<=12]]` and `[[432,12,<=12]]`
- Kasai Table A1 APM-CSS codes: `apm_kasai:p=96` and `apm_kasai:p=192`
- quantum Tanner toric-style explicit specs: `d=4,6,8`

The quantum Tanner specs are generated by the Rust helper:

```bash
target/debug/autoqec-quantum-tanner-toric-spec \
  --distance 8 \
  --fixture-id quantum-tanner-toric-d8 \
  --output benchmarks/distance_ladders/surface-toric-bb-kasai-tanner-v2/quantum_tanner_specs/toric-d8.json
```

Refresh the matrices with:

```bash
cargo run --bin autoqec-distance-ladder -- export \
  --manifest benchmarks/distance_ladders/surface-toric-bb-kasai-tanner-v2.json \
  --qec-code-bin /Users/nzy/mcode/rstim/target/release/qec-code \
  --force
```

Run the native rstim #225-style comparison with:

```bash
target/debug/autoqec-distance-rstim225 \
  --manifest benchmarks/distance_ladders/surface-toric-bb-kasai-tanner-v2.json \
  --qec-code-bin /Users/nzy/mcode/rstim/target/release/qec-code \
  --output benchmarks/distance_ladders/surface-toric-bb-kasai-tanner-v2/rstim225-native-results.csv \
  --timeout-seconds 300 \
  --iterations 5000 \
  --restarts 8 \
  --seed 20260626 \
  --max-parallel 2
```

Run the external `codedistance==0.0.8` baselines from a temporary Python
environment with:

```bash
target/debug/autoqec-distance-codedistance \
  --manifest benchmarks/distance_ladders/surface-toric-bb-kasai-tanner-v2.json \
  --python-bin /private/tmp/codedistance-venv/bin/python \
  --output benchmarks/distance_ladders/surface-toric-bb-kasai-tanner-v2/codedistance-external-results.csv \
  --timeout-seconds 300 \
  --iterations 5000 \
  --seed 20260626 \
  --max-parallel 2
```

Then create the issue-friendly comparison table with:

```bash
target/debug/autoqec-distance-wide \
  --input benchmarks/distance_ladders/surface-toric-bb-kasai-tanner-v2/rstim225-native-results.csv \
  --input benchmarks/distance_ladders/surface-toric-bb-kasai-tanner-v2/codedistance-external-results.csv \
  --csv-output benchmarks/distance_ladders/surface-toric-bb-kasai-tanner-v2/rstim225-comparison.csv \
  --md-output benchmarks/distance_ladders/surface-toric-bb-kasai-tanner-v2/rstim225-comparison.md
```

The v2 comparison table includes qec-code `random-window-upper-bound` plus
external `codedistance` `QDistRndMW`, `QDistEvol`, and `decoderDist`, all with
a 300 second per-process cap. The old qec-code `randomized-upper-bound` raw
rows remain in `rstim225-native-results.csv` for provenance but are intentionally
excluded from the comparison table. ILP is intentionally not run for the new
larger cases.
